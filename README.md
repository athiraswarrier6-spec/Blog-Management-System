# Blog Management System

## Project Overview
This is a simple Blog Management System developed using Node.js and Express.js. Users can create, view, edit, update, and delete blog posts through a responsive web interface.

## Features
- Add new blog posts
- View all blogs
- Edit existing blogs
- Delete blogs
- Responsive design
- Smooth animations and hover effects
- Deployed using Render

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Git & GitHub
- Render
